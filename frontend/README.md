# Boardly – kliens (Vue 3 + Vite)

A telepítés és az indítás leírása a [fő README-ben](../README.md) található.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # éles build a dist/ mappába
```

| Mappa / fájl | Tartalom |
| --- | --- |
| `index.html` | Az oldal váza, a favicon hivatkozásai |
| `public/` | Favicon |
| `src/assets/` | A Boardly logó |
| `src/App.vue` | Navigációs sáv és kezdőoldal |
| `src/style.css` | Stílusok |
